# SCREENSOUND APP

Um aplicativo backend desenvolvido em **C# / .NET** para ser utilizado como reprodutor de músicas e de podcasts

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** C#
* **Plataforma:** .NET (Console Application)
* **Controle de Versão:** Git & GitHub

---

## ⚙️ Funcionalidades

* Cadastrar músicas e bandas
* Cadastrar podcasts e hosts
* Exibir lista de podcasts e bandas cadastradas com seus respectivos atributos
